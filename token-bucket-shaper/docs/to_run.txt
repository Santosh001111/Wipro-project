 ## If you want to run it manually

 ### Terminal 1 — start the shaper

```
cd /home/santosh/Documents/Wipro_Project/token-bucket-shaper
sudo ./scripts/setup_iptables.sh 0
sudo ./build/tbshaper --mode police --rate 1M --burst 64K --queue 0
```

 ### Terminal 2 — start iperf3 server

```
iperf3 -s
```

 ### Terminal 3 — generate traffic

```
iperf3 -c 127.0.0.1 -t 10 -b 100M
```

 When finished, press **Ctrl+C** in Terminal 1 and then clean up:

```
cd /home/santosh/Documents/Wipro_Project/token-bucket-shaper
sudo ./scripts/teardown_iptables.sh 0
```

 ## If you modify the source code

 Then rebuild before running:

```
cd /home/santosh/Documents/Wipro_Project/token-bucket-shaper
cmake --build build
ctest --test-dir build --output-on-failure
```

 Then run the project normally.
